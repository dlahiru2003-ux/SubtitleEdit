# SubtitleEdit - Video Subtitle Encoder (v1.0.0) 
 
An ultra-fast, hardware-safe desktop utility to mux Sinhala subtitles into videos with 0%% CPU stress. 
 
## Features 
- Direct stream copy pipeline (~0%% CPU usage) 
- Subtitle muxing completed in 3-8 seconds 
- TV-ready for local and smart displays 
 
## Run 
```bash 
pip install -r requirements.txt 
python app.py 
```
